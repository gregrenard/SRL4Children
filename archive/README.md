# Archive

This folder contains legacy materials from Greg's original SRL4Children implementation.

**Status**: Not maintained. May be outdated or incompatible with the current CLI.

## Contents

### `docs/`
Original documentation including:
- HOWTO_Create_Criteria.md - Guide for creating new evaluation criteria
- Design_Principles.md - Overview of the 22 design principles
- Workflow Overview - Original pipeline documentation
- Presentation materials

### `review_ui/`
A web-based UI for reviewing evaluation results. Built with vanilla HTML/JS/CSS.

**Note**: This UI was designed for Greg's original output format and will need adaptation to work with the current CLI's SQLite database and JSON structures.
